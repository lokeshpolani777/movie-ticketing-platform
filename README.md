# Movie Ticketing Platform

A simple microservices-based movie ticketing application.

## Services

- Movie Service
- Booking Service
- Frontend

## Technologies

- Java
- Spring Boot
- MySQL
- Docker
- Docker Compose
- Git
- GitHub

## Ports

- Frontend: 8181
- Movie Service: 8081
- Booking Service: 8082
- MySQL: 3306

## Architecture

Frontend → Movie Service / Booking Service → MySQL

## CI/CD

This project uses Jenkins for continuous integration.
